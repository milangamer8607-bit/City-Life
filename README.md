# City Life – Crime & Business (Prototype 0.1)

An original third-person 3D Windows game prototype. The first build includes a procedural block city, a walkable character, a drivable/enterable car, a simple job reward loop, and a money HUD. Graphics are placeholder primitives and the project is designed to grow into a larger open-world game.

## Controls
- WASD: walk / drive
- E: enter nearby car or complete a job (+$350; cooldown)
- F: exit car
- Mouse: look around
- Esc: release mouse; click to recapture

## Build a Windows executable with GitHub
1. Create a GitHub repository and upload this project folder.
2. Open the **Actions** tab and run the workflow `Build Windows EXE` (or push to `main`).
3. Download `CityLife-Windows` from the workflow's Artifacts section.
4. Extract and launch `CityLife.exe` on Windows.

This project uses Godot 4.3 and the GL Compatibility renderer. It is an early playable prototype, not a GTA-scale finished game.
